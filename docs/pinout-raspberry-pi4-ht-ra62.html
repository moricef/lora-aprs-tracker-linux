Raspberry Pi 4B ↔ HT-RA62 / SX1262

Câblage proposé pour le tracker LoRa APRS, utilisant le contrôleur SPI0 du connecteur 40 broches. Les numéros GPIO indiqués sont les numéros BCM, pas les numéros physiques.

Attention : le HT-RA62 fonctionne en 3,3 V. Ne relier aucune de ses broches au 5 V du Raspberry Pi. Brancher une antenne 433 MHz adaptée avant toute émission.

Niveau logique : le GPS et les GPIO du Raspberry Pi utilisent 3,3 V. Ne jamais injecter un signal série 5 V dans GPIO14 ou GPIO15.

Configuration Raspberry Pi OS

  1. Activer SPI avec sudo raspi-config → Interface Options → SPI.
  2. Redémarrer avec sudo reboot.
  3. Vérifier la présence de /dev/spidev0.0.
  4. Ajouter l'utilisateur aux groupes spi et gpio.
ls -l /dev/spidev0.0
sudo usermod -aG spi,gpio "$USER"
